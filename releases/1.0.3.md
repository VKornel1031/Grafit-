# Grafit 1.0.3

Kisebb éles APK, az alkalmazásfunkciók módosítása nélkül.

- R8-kódoptimalizálás és erőforrás-zsugorítás visszakapcsolva.
- Az optimalizált DEX-fájlok tömörítve kerülnek a csomagba.
- Az Android 9+ kulcsátmeneti csomag megőrzi az 1.0.2-ben sikeresen telepített, hitelesített debug → éles aláírási történetet.
- A kiadási ellenőrzés az optimalizált APK-ban is ellenőrzi az Android indulásához szükséges konstruktort.

A bejelentkezés, szinkron, profil, helyi adattárolás, témák és CSS-változók, navigáció, jegyek, ösztöndíjbecslés és órarend kódja változatlan. A csomagazonosító és az állandó éles kulcs azonos az előző verzióéval. A frissítéshez ne távolítsd el a sikeresen telepített alkalmazást.
